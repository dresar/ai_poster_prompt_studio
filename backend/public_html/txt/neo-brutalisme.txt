GAYA VISUAL REFERENSI: Neo Brutalisme
ID: style-003
TEMA WARNA & ESTETIKA: Tema Terang Putih & Abu-Abu Muda Clean minimalis

PANDUAN PROMPTING LENGKAP:
VISUAL PHILOSOPHY: Anti-polish, anti-gradient, anti-corporate. Neo-brutalism embraces raw structural honesty — thick black outlines, visible grid blocks, harsh solid color collisions, and typography that looks stamped rather than styled. The philosophy borrows from underground zine culture and early web brutalism, repurposed for confident, punchy educational statements. DESIGN OBJECTIVE: Stop the scroll. Deliver one bold claim per composition with maximum visual friction and zero subtlety, while remaining strictly on-grid and legible. COMPOSITION RULES: Bold rectangular content blocks stacked or offset with visible thick borders (6–12px solid black strokes); blocks may slightly overlap with a hard drop-edge (no blur) to create tactile depth; asymmetric but chunky layout, never delicate. WHITE SPACE RULES: Negative space is minimal and intentional — brutalism favors dense, confident blocks over airy minimalism, but never clutter. GRID SYSTEM: Rigid modular block grid (think chunky Excel-cell structure), every element assigned to a clear cell with a visible or implied thick divider. TYPOGRAPHY HIERARCHY: Oversized condensed or slab headline (Archivo Black, Space Grotesk Bold, or Helvetica Compressed) in all-caps; body text in a plain monospace or grotesk for raw contrast against the bold headline. FONT WEIGHT: Extra-bold/black headline, regular monospace body — extreme weight contrast is the point. ALIGNMENT: Left-aligned blocky text, occasionally rotated 2–5 degrees for tension, never more. MARGINS: Tight, confident margins — content pushes close to the frame edge. SPACING: Deliberate hard gaps between color blocks (no soft transitions). ILLUSTRATION PHILOSOPHY: Flat solid-color geometric shapes (circles, stars, zig-zags, thick arrows) used as bold graphic accents rather than realistic illustration; occasional chunky flat character icons with thick black outline. OBJECT PLACEMENT: Shapes punch through borders or corners for dynamic energy. LIGHTING: None — completely flat fills. DEPTH: Achieved through hard-edged offset shadow blocks (a solid color duplicate shifted 8px behind the main shape, no blur, no gradient — a classic brutalist 'sticker shadow'). MATERIAL: Flat matte poster-print feel. TEXTURE RULES: Occasional heavy halftone dot pattern permitted as a graphic device, never as a realistic texture. SOLID COLOR RULES: High-contrast clashing but curated palette — e.g. acid yellow, hot red, cobalt blue, true black, off-white — always solid fills, thick black outlines around every shape (4–8px). ALLOWED COLORS: Saturated primary/secondary solids plus black and white. FORBIDDEN COLORS: Muted pastels, soft gradients, corporate blue-grey palettes. SHAPE LANGUAGE: Bold geometric primitives — thick stars, chunky arrows, blocky speech bubbles. ICON SYSTEM: Thick-outline flat icons matching the border weight of the layout. HUMAN ILLUSTRATION RULES: If figures appear, they are chunky flat-color cutout style with heavy black outline, exaggerated proportions, never realistic. BACKGROUND RULES: Solid loud color field or bold two-tone split background. FOREGROUND RULES: One dominant text block plus one graphic shape maximum. VISUAL HIERARCHY: Headline dominates 50%+ of frame, shape/icon supports, body text is secondary and compact. INFORMATION HIERARCHY: One punchy claim, one supporting line, done. POSTER ADAPTATION: Headline fills upper two-thirds, bold border frames entire poster. INSTAGRAM ADAPTATION: Square block grid with headline occupying a full color cell. CAROUSEL ADAPTATION: Each slide uses a different accent color from the same fixed palette for rhythm. BANNER ADAPTATION: Two-block horizontal split, text left, shape right. PRESENTATION ADAPTATION: Title slide uses full-bleed color block with stamped headline. BOOK COVER ADAPTATION: Oversized rotated title with sticker-shadow effect. THUMBNAIL ADAPTATION: Single bold word plus one shape must read instantly at small size. BRAND CONSISTENCY: Same border thickness, same offset-shadow distance, same core palette across all assets. LOGO PLACEMENT: Boxed in its own bordered cell, top corner. CTA PLACEMENT: Bold button-style block with thick border and offset shadow. ACCESSIBILITY: Extreme contrast supports readability despite loud palette. PREMIUM APPEARANCE: Achieved through confident restraint in palette size (max 4 colors) despite loud individual colors. CONSISTENCY: Border weight and shadow offset must never vary within a set.

PROMPT ENGINE V2 — AI DESIGN DIRECTOR SYSTEM. SCENE GENERATOR: never render an isolated object — build a small scene, e.g. a chunky figure slamming a fist beside a stamped 'DEADLINE' block and a clock shape; a figure pointing at an oversized arrow. BODY LANGUAGE ENGINE: choose the figure's pose (confident, shy, focused, burnout, curious, celebrating, thinking, teaching, waiting, frustrated, relaxed) from the topic's emotional core before rendering appearance, always within this style's established proportion and shading rules. VISUAL METAPHOR ENGINE: convert abstract ideas into concrete metaphors native to this style, e.g. success as a chunky trophy with sticker-shadow, growth as an arrow punching through a border. OBJECT LIBRARY: supporting props drawn only from this style's set: clock, coin stack, arrow, speech bubble, star burst (thick outline, flat fill). COMPOSITION ENGINE: rotate between Centered Hero, Left/Right Hero, Editorial Split, Comparison, Timeline, Grid Cards, Problem-Solution, Question-Answer, and Large-Number layouts, filtered through this style's grid and spacing rules, never a foreign style's conventions. LAYOUT ENGINE: reflow this identical identity — palette, illustration language, hierarchy — across Instagram Carousel/Feed, Poster, Presentation Slide, Infographic, LinkedIn, YouTube Thumbnail, Website Hero, Landing Page, Billboard, Roll Banner, Book Cover, Magazine Cover, and Worksheet formats, adjusting only scale, crop and margin. CONSISTENCY + VARIATION ENGINE: lock margins, typography, illustration language, icon style, palette, spacing, logo/footer/CTA placement and grid across a set, while guaranteeing pose, framing, object placement, composition, icon, gesture, background and metaphor never repeat identically between consecutive generations. EDITORIAL BENCHMARK: hold every output to the design register of Apple, Notion, Linear, Stripe, Pitch, Pentagram, Behance Featured, Awwwards, Adobe Design, Swiss Design and museum poster tradition.
