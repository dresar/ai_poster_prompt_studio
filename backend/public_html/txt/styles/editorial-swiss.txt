GAYA VISUAL REFERENSI: Editorial Swiss
ID: style-002
TEMA WARNA & ESTETIKA: Tema Terang Putih & Abu-Abu Muda Clean minimalis

PANDUAN PROMPTING LENGKAP:
VISUAL PHILOSOPHY: Rooted in the International Typographic Style of Müller-Brockmann and Josef Müller — objectivity, mathematical grid discipline, and typography treated as the primary image. Content is communicated through structure, not decoration. DESIGN OBJECTIVE: Produce editorial spreads that feel like they belong in a design annual or a university journal, communicating complex educational ideas through hierarchy and whitespace rather than illustration. COMPOSITION RULES: Strict asymmetric column grid (commonly 6 or 12 columns), content blocks aligned to column edges without exception; large expanses of negative space used as a compositional element, not empty leftover; a single strong focal element (a number, a rule line, or one small diagram) anchors the page. WHITE SPACE RULES: Minimum 20% of the canvas must remain empty; margins are generous and mathematically proportioned (e.g. golden ratio or 1:1.414 relationships). GRID SYSTEM: Modular Swiss grid with visible or implied baseline grid; all text and rule lines snap to the baseline. TYPOGRAPHY HIERARCHY: Four disciplined levels — Kicker (small caps, letter-spaced), Headline (very large, tight leading, Akzidenz Grotesk or Helvetica Neue Bold/Black), Subhead (medium weight), Body (Helvetica or Univers Regular, generous leading). FONT RECOMMENDATION: Helvetica Neue, Akzidenz-Grotesk, Univers, or Inter as a contemporary substitute. FONT WEIGHT: Black for headline, Regular for body, Medium for captions only. ALIGNMENT: Predominantly left-aligned, ragged right, flush-left grid discipline; occasional centered kicker for contrast. MARGINS: Wide outer margins framing the grid like a printed page. SPACING: Rule lines (hairline, 1px) used to separate sections instead of boxes or cards. NEGATIVE SPACE: Treated as a design subject — large empty quadrants intentionally balance dense text blocks (classic Swiss diagonal tension). ILLUSTRATION PHILOSOPHY: Minimal — if imagery is used, it is a single high-contrast duotone photograph or one small precise diagrammatic mark (a circle, a line chart, a single arrow), never decorative illustration. OBJECT PLACEMENT: One diagram maximum, placed off-center to create asymmetric tension against the type block. CAMERA ANGLE: If photography is used, straight-on documentary framing, no dramatic angles. LIGHTING: Flat, even, duotone-processed if photographic. DEPTH: Achieved purely through layering of grid planes, not shadow. MATERIAL: Matte paper-like flat surface with no texture overlay. SOLID COLOR RULES: Dominant palette of black, white, and one saturated primary (Swiss red #E1341E, or cobalt blue) used only for the kicker or one rule line. ALLOWED COLORS: Black, white, single primary accent. FORBIDDEN COLORS: Multi-color palettes, pastels, gradients. SHAPE LANGUAGE: Geometric rules, circles, and grid lines only — no organic shapes. ICON SYSTEM: If icons appear, they are reduced to single-line geometric marks matching rule-line weight. BACKGROUND RULES: Pure white or pure black field, no texture. FOREGROUND RULES: Type block and single diagram only. VISUAL HIERARCHY: Number/kicker draws the eye first, headline second, body third, diagram anchors the composition. EDITORIAL BALANCE: Asymmetric but mathematically justified — every element's position is grid-derived, never arbitrary. INFORMATION HIERARCHY: Strict — one headline claim, one supporting statistic, one body paragraph maximum per spread. POSTER ADAPTATION: Headline dominates 60% of the vertical space, grid visible as structural rhythm. INSTAGRAM ADAPTATION: Square format with generous margin, kicker top-left, headline center-left. CAROUSEL ADAPTATION: Consistent grid and rule-line position across every slide for rhythm. BANNER ADAPTATION: Headline left, single rule line dividing text from empty right field. PRESENTATION ADAPTATION: Slide title uses kicker+headline structure, body content confined to grid columns. BOOK COVER ADAPTATION: Title treated typographically as the entire cover image. THUMBNAIL ADAPTATION: Bold headline word alone must remain legible at small size. SOCIAL MEDIA ADAPTATION: Maintain grid ratio even when cropped to platform-specific dimensions. BRAND CONSISTENCY: Same typeface, same rule-line weight, same accent color across every piece. LOGO PLACEMENT: Small, bottom margin, aligned to grid column. CTA PLACEMENT: Bottom-right, understated, same type family as body. ACCESSIBILITY: High contrast black/white ensures readability at all sizes. PREMIUM APPEARANCE: Achieved entirely through restraint and precision, never ornamentation. CONSISTENCY: Every asset must be traceable to the same underlying grid system.

PROMPT ENGINE V2 — AI DESIGN DIRECTOR SYSTEM. CONTENT ANALYZER: before rendering, determine Main Topic, Subject, Target Audience, Communication Goal, Educational Objective, Reading Distance, Platform, Aspect Ratio, Visual Priority, Main Emotion, Tone, Story, Content Complexity and Visual Complexity, and optimize every decision below against that analysis. SCENE GENERATOR: never render an isolated object — build a small scene, e.g. an executive presenting one chart reduced to a single rule-line diagram; a lecture reduced to a podium mark and one statistic. BODY LANGUAGE ENGINE: choose the figure's pose (confident, shy, focused, burnout, curious, celebrating, thinking, teaching, waiting, frustrated, relaxed) from the topic's emotional core before rendering appearance, always within this style's established proportion and shading rules. VISUAL METAPHOR ENGINE: convert abstract ideas into concrete metaphors native to this style, e.g. growth as an ascending rule-line, failure as one broken grid cell. OBJECT LIBRARY: supporting props drawn only from this style's set: one rule line, one chart mark, one numeral — never more than one supporting object. COMPOSITION ENGINE: rotate between Centered Hero, Left/Right Hero, Editorial Split, Comparison, Timeline, Grid Cards, Problem-Solution, Question-Answer, and Large-Number layouts, filtered through this style's grid and spacing rules, never a foreign style's conventions. LAYOUT ENGINE: reflow this identical identity — palette, illustration language, hierarchy — across Instagram Carousel/Feed, Poster, Presentation Slide, Infographic, LinkedIn, YouTube Thumbnail, Website Hero, Landing Page, Billboard, Roll Banner, Book Cover, Magazine Cover, and Worksheet formats, adjusting only scale, crop and margin. CONSISTENCY + VARIATION ENGINE: lock margins, typography, illustration language, icon style, palette, spacing, logo/footer/CTA placement and grid across a set, while guaranteeing pose, framing, object placement, composition, icon, gesture, background and metaphor never repeat identically between consecutive generations. EDITORIAL BENCHMARK: hold every output to the design register of Apple, Notion, Linear, Stripe, Pitch, Pentagram, Behance Featured, Awwwards, Adobe Design, Swiss Design and museum poster tradition. QUALITY CHECK ENGINE: verify typography hierarchy, grid alignment, visual hierarchy, white space, spacing, object/icon consistency, perspective, body language legibility, storytelling clarity, color harmony, and print/thumbnail/commercial/editorial-grade quality before finalizing.
