GAYA VISUAL REFERENSI: Flat Isometrik
ID: style-009
TEMA WARNA & ESTETIKA: Tema Terang Putih & Abu-Abu Muda Clean minimalis

PANDUAN PROMPTING LENGKAP:
VISUAL PHILOSOPHY: Structured spatial storytelling through fixed-angle isometric projection — the visual language of modern SaaS onboarding illustrations and process explainers, prioritizing clarity of systems and relationships over flat single-plane simplicity. DESIGN OBJECTIVE: Explain how something works (a process, a system, a workflow, a physical or digital environment) by showing spatial relationships between objects in a consistent 3D-feeling but fully flat-shaded scene. COMPOSITION RULES: Fixed isometric grid at a true 30-degree angle on both axes; scene built from layered planes (ground plane, mid-level objects, elevated elements) to show a mini environment or process flow; a clear reading path (usually left-to-right or bottom-to-top) guides the eye through sequential steps. WHITE SPACE RULES: Moderate negative space (25–30%) framing the isometric scene so it doesn't feel cramped against the canvas edge. GRID SYSTEM: True isometric grid (30°/30°/90°) strictly maintained for every object in the scene — no object breaks the projection angle. TYPOGRAPHY HIERARCHY: Clean geometric sans headline placed outside the isometric scene (flat, front-facing, never angled to match the isometric plane), supporting labels as small flat callout chips connected to specific scene elements. FONT WEIGHT: Semi-bold headline, Regular labels. ALIGNMENT: Headline flat and horizontal at top or bottom of frame; scene occupies the remaining central area. MARGINS: Consistent frame margin so the isometric scene never touches canvas edges. SPACING: Clear gaps between isometric object clusters to avoid visual collision. ILLUSTRATION PHILOSOPHY: Every object constructed from flat-shaded geometric solids (cubes, cylinders, wedges) using exactly three tonal values per object — top face lightest, left face mid-tone, right face darkest — to imply consistent light-from-above-left logic without gradients. OBJECT PLACEMENT: Objects placed on clearly implied ground planes at consistent scale relationships (a person is always proportionate to a desk, a building, a device). SUBJECT PLACEMENT: If human figures appear, they are simplified flat-shaded isometric mannequins with the same three-tone shading logic as objects. CAMERA ANGLE: Fixed isometric (not perspective) — parallel lines never converge. LIGHTING: Implied single consistent light source from upper-left, expressed only through the three flat tonal steps, never soft gradient shading. DEPTH: Achieved entirely through layering, overlap, and the three-tone shading system — no blur, no drop shadow gradients (a single hard flat-color contact shadow beneath each object is permitted). MATERIAL: Flat matte vector surfaces throughout. TEXTURE RULES: None — pure flat color fills only. SOLID COLOR RULES: A defined palette of 4–6 flat solid colors per scene (e.g. teal, coral, cream, navy) with each object type consistently assigned its tonal triad. ALLOWED COLORS: Curated flat palette, consistent across the whole scene and future scenes in the set. FORBIDDEN COLORS: Gradient shading, glossy highlights, neon accents. SHAPE LANGUAGE: Geometric solids built strictly on the isometric axes — cubes, rectangular prisms, cylinders, simple wedge shapes. ICON SYSTEM: Flat 2D UI-style icons used only on screens-within-the-scene (like a laptop display), never breaking isometric projection themselves. BACKGROUND RULES: Solid flat color or very subtle two-tone ground/sky split behind the isometric scene. FOREGROUND RULES: Clearly staged scene objects only, no extraneous clutter outside the defined process. VISUAL HIERARCHY: Reading path (numbered or implied through arrows) guides the eye through the process steps in order. INFORMATION HIERARCHY: Each isometric cluster represents one step; labels clarify without overwhelming the scene. POSTER ADAPTATION: Full scene centered with headline banner at top. INSTAGRAM ADAPTATION: Square crop tightens the scene, keeping the full reading path intact. CAROUSEL ADAPTATION: Each slide isolates one step/object cluster from the larger scene for progressive explanation. BANNER ADAPTATION: Scene compressed horizontally, reading path left-to-right. PRESENTATION ADAPTATION: One process-scene per slide, consistent light angle and palette throughout deck. BOOK COVER ADAPTATION: Single hero isometric object/scene as the cover graphic. THUMBNAIL ADAPTATION: Simplify to the single most recognizable object cluster for small-size legibility. BRAND CONSISTENCY: Same isometric angle, same three-tone shading logic, same palette across every scene. LOGO PLACEMENT: Small flat mark, bottom corner outside the scene. ACCESSIBILITY: Ensure label chips have sufficient contrast against their connected scene elements. PREMIUM APPEARANCE: Precision of the isometric grid and consistent shading logic signal craft quality. CONSISTENCY: Every future scene must obey the identical projection angle and tonal shading rule.

PROMPT ENGINE V2 — AI DESIGN DIRECTOR SYSTEM. CONTENT ANALYZER: before rendering, determine Main Topic, Subject, Target Audience, Communication Goal, Educational Objective, Reading Distance, Platform, Aspect Ratio, Visual Priority, Main Emotion, Tone, Story, Content Complexity and Visual Complexity, and optimize every decision below against that analysis. SCENE GENERATOR: never render an isolated object — build a small scene, e.g. an isometric desk scene of a programmer with a cloud-and-server cluster above; a step-by-step isometric assembly line. BODY LANGUAGE ENGINE: choose the figure's pose (confident, shy, focused, burnout, curious, celebrating, thinking, teaching, waiting, frustrated, relaxed) from the topic's emotional core before rendering appearance, always within this style's established proportion and shading rules. VISUAL METAPHOR ENGINE: convert abstract ideas into concrete metaphors native to this style, e.g. growth as a stepped isometric staircase, workflow as a connected conveyor of blocks. OBJECT LIBRARY: supporting props drawn only from this style's set: cube desk, cylinder mug, wedge ramp, block server, mini plant cube. COMPOSITION ENGINE: rotate between Centered Hero, Left/Right Hero, Editorial Split, Comparison, Timeline, Grid Cards, Problem-Solution, Question-Answer, and Large-Number layouts, filtered through this style's grid and spacing rules, never a foreign style's conventions. LAYOUT ENGINE: reflow this identical identity — palette, illustration language, hierarchy — across Instagram Carousel/Feed, Poster, Presentation Slide, Infographic, LinkedIn, YouTube Thumbnail, Website Hero, Landing Page, Billboard, Roll Banner, Book Cover, Magazine Cover, and Worksheet formats, adjusting only scale, crop and margin. CONSISTENCY + VARIATION ENGINE: lock margins, typography, illustration language, icon style, palette, spacing, logo/footer/CTA placement and grid across a set, while guaranteeing pose, framing, object placement, composition, icon, gesture, background and metaphor never repeat identically between consecutive generations. EDITORIAL BENCHMARK: hold every output to the design register of Apple, Notion, Linear, Stripe, Pitch, Pentagram, Behance Featured, Awwwards, Adobe Design, Swiss Design and museum poster tradition. QUALITY CHECK ENGINE: verify typography hierarchy, grid alignment, visual hierarchy, white space, spacing, object/icon consistency, perspective, body language legibility, storytelling clarity, color harmony, and print/thumbnail/commercial/editorial-grade quality before finalizing.
